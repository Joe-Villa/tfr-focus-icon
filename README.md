# TFR 风格国策图标生成 · TFR Focus Icon Generator

[English](README.en.md) | 中文

给《The Fire Rises》(TFR) 及其子 mod 的国策做图标（focus icon）：
**把国策名和一句话描述交出去，拿回一张能直接进 mod 的 PNG。**

## 为什么做这个

TFR 的国策图标是它最出名的门面之一：大约 175×150 像素、透明背景、不规则轮廓、**写实照片拼贴**、
元素斜向叠压、深色描边加外发光。做一张好看的，门槛不低：要找素材、要拼、要调，做完还要缩放、
描边、配标语，最后接进 mod。国策一多，这件事就变成体力活。

这个项目把这套流程交给 AI Agent：**需求进，成品出**，中间不用人盯。

风格不是"感觉对了就行"，而是**照着 TFR 真品量化校准**过的：从 TFR 本体抽了数百张真品图标统计
（画布尺寸、内容占比、剪影实心度、半透明边比例、描边宽度、标语字号），生成后每张成品都要过
两道数字关（统计对齐 + 废品硬检查）才算合格。所以"看着像 TFR"和"数值上像 TFR"是同一件事。

**默认参数是为 TFR 调的。** 换别的画风（原版 HOI4 的扁平图标、其他风格的 mod）不是不能做，
但得自己重新校准：用 `scripts/metrics.py --stats --mod <你的真品目录>` 重算基准，
再调 design 里的 `palette / treatments / tight_target`——开箱即用的只有 TFR 这一档。

## 成本

**必须用云端的生图 API**（本地跑不了扩散模型，也不需要 GPU）。参考实现用的是硅基流动
（SiliconFlow），需要你自己的 API Key。

| 项目 | 实测 |
|---|---|
| 生图单价 | ¥0.30 / 张（官方价目页口径） |
| 交付一张图标 | **约 ¥1.8**——一轮生成 6 张候选，人（或 Agent）挑 1 张 |
| 端到端耗时 | 约 1 分钟（6 张候选 + 后处理） |
| 抠图 / 描边 / 标语 / 尺寸收口 | 本地 CPU 完成，**不花钱** |

花的钱基本等于"生成了几张图 × 单价"。想省钱可以把候选数调小，但挑的余地也小了——
扩散模型每次给的构图都不一样，多出几张再挑通常比反复精修一张更划算。
每次调用都会记账，随时能自己复算（见 `scripts/cost.py`）。

## 局限性

**先说清楚：这个项目现在只是"做出来了"，不是"已经好用了"。**

- **AI 生成的"人"是相似面孔，不是真人**。真实 mod 的图标常用真人照片与历史影像，这里做不到，
  只能生成"长得像"的人。要做特定历史人物，得先接受这一点。
- **分层感不如手工做的**。整块生成出来的画面，元素之间缺少"多个贴片斜向叠压"的纵深；
  要那种质感得走元素拼贴路线，成本翻倍且更费人工。
- **模型偶尔会在主体下方画一层地面反光**，抠完留一条浅灰带，负面提示词只能减少不能杜绝，
  目前靠多出候选、挑一张干净的绕过。
- **内容审核是随机的**，同一句提示词有时过有时不过。更关键的是：题材本身不合适就做不了——
  真实政治人物、真实军事题材不在适用范围，重试也救不回来。
- **只在一台机器上验证过**。仓库里有一个不花钱的冒烟自检（`selftest.sh`，10 项），但**没有真正的
  测试套件**，也没在干净环境跑过。
- **细节还不稳**：小字在 150 像素下会糊成纹理；标语是本地叠上去的（清晰、可改，但"贴"的痕迹在）。

## 怎么用

把它作为 skill 装进 Codex（或任何能读 `SKILL.md` 的 Agent），然后**直接用一句话提需求**——
国策名、国家、画面想表达什么。剩下的（写提示词、出候选、抠图、过验收、装进 mod）Agent 会自己走完。

这里不写操作步骤，因为使用者是 Agent，不是人。

## 仓库里有什么

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 给 Agent 读的完整工作流与硬规则（Agent 的入口） |
| `references/` | 细节：风格卡与量化基准、拼贴构图、踩坑与排查表、接入 mod、子 Agent 分工、用视觉模型自评 |
| `scripts/` | 可直接调用的工具：出图驱动、API 客户端、抠图、后处理、客观指标、废品检查、计费账本、参考图闸门、真品对照图拼版 |
| `install.sh` | 装进 Codex 的安装脚本（把本仓库拷进 `$CODEX_HOME/skills/`） |
| `selftest.sh` | 自检：把编译、闸门（坏图必须被拦）、指标、账本汇总跑一遍，**不联网、不花 API 钱** |
| `requirements.txt` | 运行依赖（Pillow / numpy / scipy / onnxruntime），另需一个中文字体 |

**本仓库不含任何参考图**：真实 mod 的图标属于他人作品，不随包分发。需要风格基准时，
Agent 会指向你自己那份 HOI4 安装目录。
